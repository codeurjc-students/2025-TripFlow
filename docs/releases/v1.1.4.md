# 📦 TripFlow - Release v1.1.4

---

> **🧭 Summary**
>
> Patch release **1.1.4** of **TripFlow**. Fixes browsers showing the previous frontend build after a deploy: the service worker now reloads the page once an update takes over, and every HTML response is served with `Cache-Control: no-cache`.

---

## 📄 Release Notes

### 🐛 Bug Fixes

- **Stale app after deploys**: the service worker installed new builds in the background but never reloaded the page, so the first visit after a deploy showed the previous version until a manual refresh. The app now registers the worker through `virtual:pwa-register`, which reloads the page once the updated worker takes control.
- **Missing cache headers on prerendered pages**: `/`, `/help` and `/privacy` were served without `Cache-Control`, letting browsers reuse them for days through heuristic caching. They now return `Cache-Control: no-cache`.

### 🏷️ Version

- Frontend and all backend modules bumped to **1.1.4**.
