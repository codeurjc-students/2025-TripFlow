# 📦 TripFlow - Release v1.1.3

---

> **🧭 Summary**
>
> Patch release **1.1.3** of **TripFlow**. Reverts the map tile provider from Stadia Maps back to CARTO basemaps (dark_all) with API key authentication. CARTO is the most stable long-term option: free for non-commercial use, 5 million tile requests/month, and no account required. The API key is read from the `PUBLIC_CARTO_API_KEY` environment variable.

---

## 📄 Release Notes

### 🐛 Bug Fixes

- **Map tile provider reverted to CARTO**: switched from Stadia Maps back to CARTO `dark_all` tiles, which originally broke due to a transient issue and are now stable. CARTO requires a free API key (no account needed, 5M requests/month for non-commercial use).
- **Tinting filter restored**: reverted the CSS tile filter to the original CartoDB values (`brightness` 1.2, `saturate` 2, `hue-rotate` 170°) that match CARTO's dark tiles.
- **CSP updated**: replaced Stadia Maps domain with `*.basemaps.cartocdn.com` in the nginx `img-src` directive.

### ⚙️ Configuration

- **API key via env var**: the CARTO API key is read from `PUBLIC_CARTO_API_KEY` (Vite's `PUBLIC_` prefix exposes it to the client). Add your key to a `.env` file in `frontend/` — see `.env.example`.

### 🏷️ Version

- Frontend and all backend modules bumped to **1.1.3**.
