# 📦 TripFlow - Release v1.0.2

---

> **🧭 Summary**
>
> Patch release **1.0.2** of **TripFlow**. Driven by a full Lighthouse audit of the frontend, this release dramatically improves web performance (initial JavaScript payload reduced by ~85%), fixes WCAG AA contrast issues, and makes the app discoverable by search engines and AI agents. No application features change — this is a frontend performance, accessibility, and SEO maintenance release.

---

## 📄 Release Notes

### ⚡ Performance

- **Route-level code splitting**: all pages except the landing are now lazy-loaded. The initial JavaScript bundle drops from **2136 KiB to 311 KiB** and the initial CSS from **139 KiB to 51 KiB**.
- **On-demand PDF renderer**: `@react-pdf/renderer` (~1.5 MiB) is now loaded only when exporting an itinerary to PDF, instead of shipping with the itinerary detail page.
- **WebP showcase images**: the landing and AI CTA background images were converted from PNG (**1.2 MiB**) to WebP (**85 KiB**) with no visible quality loss.
- **Self-hosted fonts**: Inter is now served from the app itself as subsetted `woff2` files, removing the render-blocking Google Fonts request chain (and an unused Geist download). The main subset is preloaded from the HTML.
- **Layout stability**: the mobile showcase image declares explicit dimensions so the browser reserves its space (CLS).
- **Better caching**: nginx now serves `webp`, `avif`, and `woff2` assets with a 1-year cache lifetime, matching the existing policy for hashed assets.

### ♿ Accessibility

- **WCAG AA contrast**: primary buttons and status badges now meet the 4.5:1 contrast ratio. Backgrounds were darkened one step (`--primary-strong`, `--active-strong`, `--draft-strong`) while keeping white labels, preserving the original look.

### 🔍 SEO & AI Agents

- **Meta description** added to the document head.
- **`robots.txt`** added — crawlers previously received the SPA fallback HTML, which parsed as an invalid robots file.
- **`llms.txt`** added, describing the app and its public routes with Markdown links for AI-agent navigation.

### 🌐 Infrastructure

- **Tightened CSP**: the Google Fonts origins were removed from `style-src` and `font-src` now that fonts are self-hosted.
